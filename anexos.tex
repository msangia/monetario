\section*{Anexo A. Pronóstico diario de liquidez (Eje 1)}
\textbf{Responde a}: Eje 1, funciones 1 y 5. Propuesta: ensamble con efectos de calendario contra un benchmark ingenuo, medido por error absoluto medio relativo, sesgo por día del mes, cobertura de intervalos y test de Diebold-Mariano al 10\,\% con al menos 60 días.
\textbf{Método}: se pronostica a un día la variación diaria (\%) de la serie. Hay dos modelos, una regresión con variables de calendario (inicio y fin de mes, quincena, aguinaldo, diciembre, lunes) y un ARIMAX (AR(1) en espacio de estado), y el ensamble es su promedio simple. El benchmark es la variación nula. La evaluación es fuera de muestra con ventana expansiva: los parámetros se reestiman cada 60 días, sin \emph{look-ahead}. El test de Diebold-Mariano lleva la corrección de Harvey, Leybourne y Newbold (HLN).
\begin{lstlisting}[language=Python]
# Fragmento abreviado de codigo/monetario_demo/liquidez.py
for t0 in range(n0, len(y), cada):             # ventana expansiva
    t1 = min(t0 + cada, len(y))

    q = float(np.quantile(np.abs(y_tr), 1 - ALFA))           # benchmark ingenuo
    salida["ingenuo"].append(pd.DataFrame({"obs": obs, "pron": 0.0, "inf": -q, "sup": q}))
    pr = sm.OLS(y_tr, X_tr).fit().get_prediction(X_te).summary_frame(alpha=ALFA)
    ...                                        # regresión con calendario
    res = SARIMAX(y_tr.to_numpy(), exog=ex_tr, order=(1, 0, 0), trend="c").fit(disp=False)
    pa = res.append(obs.to_numpy(), exog=ex_te).get_prediction(start=t0, end=t1 - 1)
    ...                                        # ARIMAX: filtrado un paso adelante
out["ensamble"] = (out["regresion"] + out["arimax"]) / 2
dm = diebold_mariano(e_ens, e_ing, h=1, perdida="abs", alternativa="menor")  # HLN
\end{lstlisting}

\section*{Anexo B. Demanda de dinero en ventanas móviles (Eje 4)}
\textbf{Responde a}: Eje 4, función 4, primer bloque de la programación. Propuesta: modelo de corrección de errores en ventanas móviles para la base y el M2 privado.
\textbf{Método}: Engle-Granger en dos pasos con $m-p$ (dinero real), $y$ (actividad, EMAE) e $i$ (costo de oportunidad), en ventanas de 72 meses. Una alerta indica que $b_y$ o $b_i$ se alejó de la primera ventana más que un umbral simulado bajo estabilidad: es un \emph{bootstrap} paramétrico con error AR(1) corregido por sesgo, con falsa alarma nominal del 10\,\% por coeficiente en toda la muestra. Se informa además el CUSUM del modelo de corto plazo.
\begin{lstlisting}[language=Python]
# Fragmento abreviado de codigo/monetario_demo/demanda_dinero.py (umbral_simulado y alerta)
beta = np.linalg.lstsq(X[:ventana], m[:ventana], rcond=None)[0]   # ventana de referencia
u = m[:ventana] - X[:ventana] @ beta
...                                        # phi del AR(1) de u, corregido por sesgo
maximos = np.empty((B, 2))
for b in range(B):                         # B muestras sin quiebre
    us = _simular_u(phi, sigma, len(df))
    bm = _betas_moviles(X @ beta + us, X, ventana)[:, 1:]
    maximos[b] = np.abs(bm - bm[0]).max(axis=0)
q = np.quantile(maximos, nivel, axis=0)    # umbral de b_y y b_i
...
fuera = (rol[coef] - rol[coef].iloc[0]).abs() > umbral[coef]
out[coef] = fuera.idxmax() if fuera.any() else None   # primera alerta
\end{lstlisting}
\textbf{Uso}: \texttt{python -m monetario\_demo.demanda\_dinero -{}-demo}. \sintetico{} El generador incluye un quiebre de $b_i$ (de $-2$ a $-4$) en 2016-01.

\section*{Anexo C. Banda de tolerancia y desvíos (Eje 4)}
\textbf{Responde a}: Eje 4, función 4, tercer bloque de la programación, e indicador (vi) del proyecto. Propuesta: banda de tolerancia para base y M2 derivada del error histórico, revisada cada mes, con nota si se excede.
\textbf{Método}: errores históricos (\%) del programa a 1--3 meses. La banda central del 90\,\% sale de sus cuantiles empíricos y usa sólo errores ya observados al armar cada programa. Cada mes del trimestre queda clasificado como \emph{dentro} o \emph{fuera de banda}.
\begin{lstlisting}[language=Python]
# Fragmento abreviado de codigo/monetario_demo/bandas.py (banda_tolerancia y chequeo)
pos_corte = errores.index.get_indexer([corte], method="pad")[0]
for h in errores.columns:                  # h = 1, 2, 3 meses
    e = errores[h].iloc[: max(pos_corte - h + 1, 0)].dropna()   # conocidos al corte
    out[h] = {f"{lado}_{int(n * 100)}": float(np.quantile(e, q))
              for n in niveles for lado, q in (("inf", (1 - n) / 2), ("sup", (1 + n) / 2))}
...
desvio = 100 * (lg.iloc[t + h] - prog)     # observado frente a programa (%)
estado = "dentro de banda" if inf <= desvio <= sup else "fuera de banda"
\end{lstlisting}
\textbf{Uso}: \texttt{python -m monetario\_demo.bandas -{}-demo -{}-figura salidas/fan\_chart\_demo.pdf}. \sintetico{} Se agregó un \emph{shock} sintético en los dos últimos meses.
